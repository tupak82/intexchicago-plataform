# Intex Chicago Platform

Modern replacement for the legacy WordPress site at `intexchicago.com`.

## Goals

- Fast, mobile-first restoration and roofing website
- Strong technical SEO and local SEO foundations
- Clean migration away from legacy WordPress code
- High-conversion emergency and estimate flows
- Structured, reusable service and location pages
- Secure deployment from GitHub

## Stack

- Next.js 16.3
- React 19.2
- TypeScript
- App Router

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Migration rule

The legacy WordPress website is treated as a content source only. Do not copy themes, plugins, injected HTML, or unknown scripts into this repository.
